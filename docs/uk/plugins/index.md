# Плагіни

Плагін додає одну частину збірки. Цей розділ має сторінку для
кожного плагіна, і кожна сторінка відповідає на те саме питання:
**що він додає і чому?**

## Що може додати плагін

| Вид                   | Що це                                               | Як використовується          |
| --------------------- | --------------------------------------------------- | ---------------------------- |
| **Файли**             | [Артефакти](/uk/format/artifacts) для встановлення. | Вони просто встановлюються.  |
| **Змінні**            | [Іменовані значення](/uk/format/variables).         | `${java_home}` будь-де.      |
| **Фрагменти запуску** | Іменовані частини командного рядка.                 | `'@forge.jvmArgs'` в `args`. |
| **Середовище**        | Змінні середовища для гри.                          | Встановлюються автоматично.  |

І нічого більше. Плагін працює лише під час збирання, і ніщо з
нього не потрапляє на комп'ютер гравця.

## Будь-яка збірка

|                                | Плагін  | Що робить                                                 |
| ------------------------------ | ------- | --------------------------------------------------------- |
| [Локальні файли](./files)      | `files` | Встановлює теку з вашого диска.                           |
| [Файли за посиланням](./links) | `links` | Встановлює файл, на який ви маєте URL, закріплений хешем. |

Обидва приймають функцію `to`, яка каже, куди встановлюється
кожен файл:

```js
to: (file) => '${game_directory}/mods/' + file.filename,
```

## Minecraft

|                                             | Плагін           | Що робить                                              |
| ------------------------------------------- | ---------------- | ------------------------------------------------------ |
| [Ванільний Minecraft](./minecraft)          | `minecraft`      | Гра в тому вигляді, як її постачає Mojang.             |
| [Список серверів](./serverlist)             | `serverlist`     | Заповнює список серверів для багатокористувацької гри. |
| [Власний сервер авторизації](./authliberty) | `authliberty`    | Спрямовує гру на ваш власний сервер облікових записів. |
| [Bifrost](./bifrost)                        | `resolveBifrost` | Створює токен входу гравця під час запуску.            |

## Завантажувачі модів для Minecraft

Використовуйте один **замість** `minecraft`. Кожен завантажувач
включає гру.

|                          | Плагін      | Що робить                                       |
| ------------------------ | ----------- | ----------------------------------------------- |
| [Forge](./forge)         | `forge`     | Моди Forge, Minecraft 1.1 і пізніші.            |
| [NeoForge](./neoforge)   | `neoforge`  | Моди NeoForge, 1.20.2 і пізніші.                |
| [Fabric](./fabric)       | `fabric`    | Моди Fabric.                                    |
| [Cleanroom](./cleanroom) | `cleanroom` | Моди Forge 1.12.2 на сучасному середовищі Java. |
| [lwjgl3ify](./lwjgl3ify) | `lwjgl3ify` | Моди Forge 1.7.10 на сучасному середовищі Java. |

знаходиться в `@opys/dev`.
