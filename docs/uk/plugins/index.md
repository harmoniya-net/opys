# Плагіни

Плагін додає частину маніфесту: файли, змінні або фрагменти команди запуску. Цей розділ має окрему сторінку для кожного плагіна з його параметрами, внеском і прикладом. Про те, як плагіни поєднуються між собою, читайте в розділі [«Основні поняття»](/uk/guide/concepts).

Кожен плагін нижче експортується з `@opys/minecraft`, який реекспортує окремі пакети, крім `files`, що походить з `@opys/dev`. Якщо потрібен лише один, встановіть його окремий пакет. `bifrost` є єдиним записом, який є функцією, а не плагіном.

## Гра {#the-game}

Перші шість додають цілу гру включно з ванільними файлами, тому конфігурація використовує один з них, а не два. Поруч додайте [`java`](./java).

| Плагін                     | Пакет                     | Що додає                                                                     |
| -------------------------- | ------------------------- | ---------------------------------------------------------------------------- |
| [`minecraft`](./minecraft) | `@opys/minecraft-vanilla` | Ванільний клієнт, його бібліотеки та ресурси гри                             |
| [`forge`](./forge)         | `@opys/forge`             | Forge для кожної версії Minecraft з його індексу, починаючи від 1.1          |
| [`neoforge`](./neoforge)   | `@opys/neoforge`          | NeoForge для кожної версії Minecraft з його індексу, починаючи від 1.20.2    |
| [`fabric`](./fabric)       | `@opys/fabric`            | Fabric для будь-якої версії Minecraft, для якої Fabric Meta має завантажувач |
| [`cleanroom`](./cleanroom) | `@opys/cleanroom`         | Cleanroom, наступник Forge для 1.12.2, на сучасному Java                     |
| [`lwjgl3ify`](./lwjgl3ify) | `@opys/lwjgl3ify`         | lwjgl3ify, Forge 1.7.10 на LWJGL 3 і сучасному Java                          |
| [`java`](./java)           | `@opys/java`              | Середовище Java для кожної платформи                                         |

## Під капотом {#underneath}

Це не плагіни. Це пакети, на яких побудовані плагіни та лаунчери.

| Пакет                                            | Що це                                                                       |
| ------------------------------------------------ | --------------------------------------------------------------------------- |
| [`@opys/dev`](./dev)                             | SDK для збирання: `defineConfig`, контракт плагінів, рушій збирання         |
| [`@opys/core`](./core)                           | Модель даних маніфесту та бандл                                             |
| [`@opys/runtime`](./runtime)                     | Інсталятор і лаунчер                                                        |
| [`@opys/mojang`](./mojang)                       | Парсери власних форматів Mojang                                             |
| [`@opys/mojang-rules`](./mojang-rules)           | Типи формату правил Mojang                                                  |
| [`@opys/minecraft-vanilla`](./minecraft-vanilla) | Відображення з документа версії в маніфест, спільне для всіх завантажувачів |
