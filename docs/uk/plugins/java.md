# java

`java()` дає середовище Java для кожної платформи, щоб гра працювала на JDK, який встановлює opys, а не на тому, що є на машині запуску. Додайте `java('21')` до `plugins`, а далі вкажіть команду запуску на `java.bin`. JDK надходить з Eclipse Temurin, якщо параметром `vendor` не вибрано Azul Zulu чи GraalVM Community Edition. Під час збирання opys запитує в API постачальника по одному архіву на платформу і фіксує його sha256. Машина запуску завантажує й розпаковує лише архів для власної платформи. Ця сторінка для авторів модпаків. Про те, яка Java потрібна кожній версії Minecraft, див. [Java](/uk/guide/java).

## Сигнатура {#signature}

```ts
java(version: string, options?: {
  vendor?: 'temurin' | 'zulu' | 'graalvm';
  platforms?: { os: 'linux' | 'osx' | 'windows'; arch: 'x86_64' | 'aarch64' }[];
  apiBase?: string;
  token?: string;
}): ChainablePlugin
```

`version` це перший аргумент, і це рядок. `java({ version: '17' })` відхиляється з `TypeError`, який показує правильний виклик. Виклик `java()` не виконує мережевої роботи; пошуки відбуваються, коли `opys build` або `opys launch` збирає конфігурацію. Він експортується з `@opys/minecraft` і з `@opys/java`, який також експортує резолвер кожного постачальника (`resolveTemurin`, `resolveZulu`, `resolveGraalvm`), якщо метадані релізу потрібні без плагіна.

## Версія {#version}

`version` приймає мажорну версію або точну збірку. Які саме написання працюють, залежить від постачальника.

| Ввід                | Постачальник | Визначається як                                                                                                        |
| ------------------- | ------------ | ---------------------------------------------------------------------------------------------------------------------- |
| `'21'`              | all          | Останній реліз мажорної 21. Для `graalvm` найновіший реліз `jdk-21.*`                                                  |
| `'21.0.12.1+1'`     | `temurin`    | Той реліз Adoptium. Префікс `jdk-` додається                                                                           |
| `'jdk-21.0.12.1+1'` | `temurin`    | Той самий реліз, записаний повним іменем                                                                               |
| `'8u492-b09'`       | `temurin`    | Реліз Java 8 `jdk8u492-b09`                                                                                            |
| `'21.0.12'`         | `temurin`    | Завершується з "No Temurin binaries found". Імена релізів Temurin мають номер збірки, тому подавайте повну форму       |
| `'21.0.12'`         | `zulu`       | Передається в Azul як `java_version`. Повернута збірка може мати довшу версію: `21.0.12` повернувся як JDK `21.0.12.1` |
| `'21.0.2'`          | `graalvm`    | Реліз з тегом `jdk-21.0.2`                                                                                             |
| `'jdk-21.0.2'`      | `graalvm`    | Реліз із тим тегом, використаний як записано                                                                           |
| `'graal-25.2.4'`    | `graalvm`    | Завершується помилкою. Підтримуються лише теги виду `jdk-<major>.…`                                                    |

Збирання друкує реліз, який визначено, як `[java] Temurin 21.0.12.1+1`. Перевіряйте той рядок після зміни версії.

## Параметри {#options}

| Параметр    | Тип                                | Типово                                                                                                           | Значення                                                                                                                                                              |
| ----------- | ---------------------------------- | ---------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `vendor`    | `'temurin' \| 'zulu' \| 'graalvm'` | `'temurin'`                                                                                                      | Дистрибутив. `temurin` це Eclipse Adoptium, `zulu` це Azul Zulu, `graalvm` це GraalVM Community Edition                                                               |
| `platforms` | `{ os, arch }[]`                   | Шість платформ із розділу [Платформи](#platforms)                                                                | Платформи для забезпечення. `os` це `'linux'`, `'osx'` або `'windows'`; `arch` це `'x86_64'` або `'aarch64'`. Платформа, якої постачальник не постачає, пропускається |
| `apiBase`   | `string`                           | Adoptium `https://api.adoptium.net/v3`, Azul `https://api.azul.com/metadata/v1`, GitHub `https://api.github.com` | Базова URL API постачальника. Встановіть її для дзеркала або для API GitHub Enterprise з `graalvm`                                                                    |
| `token`     | `string`                           | Немає                                                                                                            | Токен GitHub, щоб підняти ліміт частоти API. Використовується лише в `graalvm`. Він використовується під час збирання і не записується в бандл                        |

Щоб використати іншого постачальника, передайте параметр другим аргументом:

```js
java('21', { vendor: 'zulu' });
```

## Групи запуску {#launch-groups}

Плагін називається `java`, тому його група читається як `java.bin` у `manifest.command`.

| Група      | Тип    | Містить       |
| ---------- | ------ | ------------- |
| `java.bin` | string | `${java_bin}` |

Використовуйте її як `command: ({ java }) => java.bin`.

## Змінні {#variables}

Плагін володіє цими змінними. Жоден інший плагін не має їх визначати.

| Змінна             | Значення                          | Значення                                                                                                    |
| ------------------ | --------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `java_runtime_dir` | `${root}/runtimes`                | Де архіви завантажуються, а JDK розпаковуються. Він іде за `root`, тому встановлювати його доводиться рідко |
| `java_home`        | `${java_runtime_dir}/jdk-<major>` | Каталог JDK. На macOS він закінчується на `/Contents/Home`                                                  |
| `java_bin`         | Див. нижче                        | Виконуваний файл Java                                                                                       |

`java_bin` це `${java_home}/bin/java` на Linux і macOS. На Windows це `${java_home}/bin/javaw.exe`, який стартує без вікна консолі. З увімкненою ознакою `java_console` це натомість `${java_home}/bin/java.exe`, тому вивід гри видно. Увімкніть ознаку через `opys launch --feature java_console`.

Плагін також встановлює змінну середовища `JAVA_HOME` у значення `${java_home}` в маніфесті. Інструменти, які стартують із запуском, такі як [dgpuj](./dgpuj), знаходять JDK через неї.

## Платформи {#platforms}

Типово плагін забезпечує шість платформ:

- Linux, `x86_64` і `aarch64`
- macOS (`osx`), `x86_64` і `aarch64`
- Windows, `x86_64` і `aarch64`

Постачальники постачають не кожну платформу для кожної версії. На момент написання:

| Ввід                        | Платформи, що визначилися                                                      |
| --------------------------- | ------------------------------------------------------------------------------ |
| `temurin` `'21'`            | Усі шість                                                                      |
| `temurin` `'17'` або `'25'` | П’ять. Немає збірки Windows `aarch64`                                          |
| `temurin` `'8'`             | Чотири. Немає збірок macOS `aarch64` і Windows `aarch64`                       |
| `zulu` `'21'` або `'25'`    | Усі шість. Збірки Linux це збірки glibc, тому системи musl не отримують жодної |
| `zulu` `'7'`                | Три. `x86_64` на Linux, macOS і Windows                                        |
| `graalvm` `'21.0.2'`        | П’ять. Немає збірки Windows `aarch64`                                          |

Платформа без збірки пропускається. Для мажорної версії Temurin і Zulu запитуються один раз на платформу, і платформа, чий найновіший реліз відрізняється від того, на якому зійшлася більшість платформ, теж відкидається, щоб кожна платформа отримала один реліз. Якщо не визначається жодна платформа, збирання завершується помилкою. Якщо машина запуску працює на платформі, яку пропущено, вона не отримує JDK, тому перед постачанням бандла для тієї платформи перевірте список постачальника.

## Цілісність {#integrity}

Кожен архів зафіксовано за його sha256. Temurin і Zulu беруть його зі своїх API. GraalVM бере його з дайджесту файла релізу GitHub або з файла `.sha256` поруч з архівом для старіших релізів. Якщо немає жодного, збирання завершується помилкою замість постачання неперевіреного JDK.

## Приклад {#example}

Додайте `java` до `plugins` і використайте `java.bin` як команду:

```js
plugins: [minecraft('1.21.1'), java('21')],
manifest: {
  command: ({ java }) => java.bin,
  args: ({ minecraft }) => [
    minecraft.jvmArgs,
    minecraft.mainClass,
    minecraft.gameArgs,
  ],
},
```

Плагін дає лише бінарний файл. Аргументи й далі надходять з ігрового плагіна, яким тут є `minecraft`. Конфігурація `forge` або `fabric` така сама, з групами того плагіна в `args`. Повний приклад нижче використовує типового постачальника і запускає ванільну 1.21.1:
